# 开发计划

## 阶段 1：项目骨架

- 建立 C++/CMake 项目结构。
- 添加命令行启动入口。
- 添加修改项、配置、进程接口的基础模块。

## 阶段 2：进程附加

- 根据进程名查找目标游戏。
- 打开目标进程句柄。
- 显示附加状态和失败原因。

## 阶段 3：内存读写

- 封装安全的读取和写入函数。
- 对地址、进程状态和权限做检查。
- 避免直接散落调用系统 API。

## 阶段 4：修改项系统

- 每个修改项包含名称、说明、启用状态和执行逻辑。
- 支持启用、禁用和状态显示。
- 后续支持热键绑定。

## 阶段 5：界面

- 初期保留命令行，便于调试。
- 稳定后再选择 Win32、Qt 或 ImGui 图形界面。
